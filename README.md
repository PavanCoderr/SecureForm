# SecureForm — Smart Login & Signup Validation System

A frontend-only project demonstrating modern form validation.

## Features
- Login and signup modes
- Real-time email validation
- Password strength meter with five requirements
- Common-password pattern warning
- Confirm-password matching
- Full-name validation
- Terms acceptance
- Show/hide password controls
- Accessible live status feedback
- Responsive glassmorphism UI
- Privacy-first demo: no network requests and no credential storage

## Run
Open `index.html` in a modern browser. No server or dependency installation is required.

## Important
This is an educational client-side prototype. Production authentication must also perform server-side validation, secure password hashing, CSRF protection, rate limiting, session management, HTTPS, and appropriate account/email verification.
